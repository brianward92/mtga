\begin{abstract}
This is the companion reference for ``DraftFM: Zero-Shot Drafting of
Unseen \mtg{} Sets from Public Card Features.'' The main paper is the
scientific story: modeling decisions, the pre-registered protocol,
results, and an honest self-assessment of what it does and doesn't show.
This document is the short, structured ``how it's actually built and
reproduced'' reference instead -- released code layout, the provenance
mechanics behind every number in the main paper, and the frozen
identifiers that pin the evaluation. Read the main paper first.
\end{abstract}

\section{What's released}
\label{sec:released}

Training and evaluation code, the frozen protocol document and metric
implementations, data and featurizer manifests, model weights for every
battery member, and the per-pick prediction files from which every
statistic in the main paper is computed (archived on Zenodo). Raw
\seventeenlands{} bytes for the MSH test snapshot are deposited only
after a courtesy note to \seventeenlands{}; every other input is
re-derivable from public sources via the manifests below.

\section{Provenance mechanics}
\label{sec:ledger}

Every training and evaluation run appends one record to an append-only
ledger: run id, git sha, protocol tag, seed, framework version, full
config, data-manifest hash, wall clock, throughput, artifact sha256s, and
dev metrics. Every table cell in the main paper carries its source run
id as a comment in the generated table file; tables and the scaling
figure are emitted by a script from run records and cached evaluation
outputs, and the main paper's prose reads numbers from generated macros
-- no result number in either document is typed by hand.

\begin{itemize}
  \item \texttt{experiments/ledger.jsonl} -- the append-only run registry
  \item \texttt{scripts/make\_paper\_tables.py} -- emits every table and
    the scaling-figure data from ledger + run records; regenerate after
    any new run lands
  \item \texttt{figures/make\_verdict\_panels.py} -- computes the real,
    live-scored numbers in the illustrative verdict-panel figures via
    the same \texttt{mtga.models.registry} / \texttt{mtga.draft\_api.HUB}
    code path the deployed overlay uses
  \item \texttt{figures/fetch\_example\_cards.py} -- fetches the card
    images used in those figures directly from Scryfall's hosted URLs,
    writing \texttt{figures/cards/manifest.json} with the exact source
    URL, artist, and copyright line per card
\end{itemize}
