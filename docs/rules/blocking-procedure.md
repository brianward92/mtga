# Declaring blockers procedure

<!-- procedure: declare-blockers -->

This is the canonical blocking procedure. Other documents should link here instead of copying it.

1. Check survival. Sum attacker power and block enough to stay above zero life, accounting for trample and plausible instant-speed increases.
2. Take free blocks where the blocker survives and either kills or walls the attacker.
3. Trade when the exchange improves the side whose role is defensive or removes the more valuable creature.
4. Chump only when survival requires it or the blocker has no more useful job.
5. Gang block only when combined power kills the attacker and the likely damage assignment is acceptable. Menace requires at least two blockers.
6. Recalculate after accounting for available colours, mana, tricks, first strike, double strike, deathtouch, trample, and existing continuous effects.
7. Submit only after every attacker and blocker has been checked once. A blocked non-trampling attacker remains blocked if its blocker is removed (CR 509.1h and 510.1c).

The attacking player receives priority first after blockers are declared (CR 509.2), so the defending player normally gets the last response before combat damage.
