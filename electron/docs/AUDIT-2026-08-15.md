## 3. DraftFM local-inference contract (verified live against `n41.local:/opt/bward/dat/mtga/models/_foundation/latest` → `f-full-20260705`)

Reference implementation: `mtga/models/draftfm.py` (`OnnxDraftFMModel`), `mtga/models/base.py` (`rank_scores`), export in `mtga/foundation/export.py` L190-287, 450-470; architecture `mtga/foundation/model.py` L57-186.

### 3.1 Model bundle (`models/_foundation/<tag>/`)

| File | Contents |
|---|---|
| `card_encoder.onnx` + `card_encoder.onnx.data` (2.1 MB) | input `features` f32 `[n_cards, 775]` → output `card_emb` f32 `[n_cards, 256]`. Ops: ReduceMean, Sub, Mul, Add, Sqrt, Div, Gemm, Erf |
| `scorer.onnx` + `scorer.onnx.data` (4.4 MB) | 10 inputs (exact names/dtypes): `pool_emb` f32 `[B,P,256]`, `pool_counts` int64 `[B,P]`, `pool_mask` bool `[B,P]`, `pack_emb` f32 `[B,K,256]`, `pack_mask` bool `[B,K]`, `wr_id` int64 `[B]`, `games_id` int64 `[B]`, `format_id` int64 `[B]`, `position` f32 `[B,7]`, `set_scalars` f32 `[B,4]` → `logits` f32 `[B,K]` (−inf where masked). All axes dynamic. ir_version 10, opset 18 |
| `constants.npz` | `pool_null_input` f32 `[256]` |
| `meta.json` | `model_id` (`_foundation/f-full-20260705`), `kind` `draftfm-zeroshot`, `manifest_hash` `e1313cad…9f6`, `serving {wr_id:33, games_id:6}`, `set_ctx:false`, `feat_dim:775`, `d_model:256`, `opset:18` |

`set_ctx=false` ⇒ NO `set_encoder.onnx`, NO `set_summary` input. `.onnx.data` files must sit next to the `.onnx` with the same basename. Any onnxruntime binding (`onnxruntime-node`) runs both graphs unchanged (CPU EP).

Serving-ID semantics (`mtga/foundation/dataset.py` L37-58): `wr_id = round(wr*50)` clipped [15,45], 255 = missing → 33 ≈ 0.66 win-rate; `games_id` indexes `[1,5,10,50,100,500,1000]` → 6 = 1000+ games. `format_id`: PremierDraft 0, TradDraft 1, else 2 (`draftfm.py` L29-33). Note the paper's sealed HOB forecast used wr_id 28 / games_id 4 — the app's ratings deliberately differ.

### 3.2 Per-set assets (`foundation/set_assets/<SET>.npz`, built by `scripts/build_set_assets.py` L175-207)

| Key | Type | Meaning |
|---|---|---|
| `features` | f16 `[N,775]` | cols 0..390 struct (frozen `cardfeats_v1` manifest), 391..774 bge-small-en-v1.5 text (L2-normed) |
| `rarity_ids` | u8 `[N]` | only used by set_ctx=true exports (ignore) |
| `names` | `<U` `[N]` | 17Lands display names, row order = universe order |
| `grp_ids` | 0-d `<U` JSON | `{name: [grpId, …]}` all alias printings |
| `manifest_hash` | 0-d str | must equal `meta.manifest_hash` else refuse (draftfm.py L93-99) |
| `picks_per_pack` | 0-d int64 | 0/None → 14 |
| `set`, `text_missing` (JSON list), `built_at` | — | provenance |

Verified: MSH `(334,775)`, ppp 14, `text_missing []`; ECL 301 names, 155 with >1 alias, non-empty `text_missing` (zero-filled text rows are already accepted in production).

**Port recommendation:** define a TS-friendly bundle: `assets.json` `{set, manifest_hash, model_id, picks_per_pack, names[], grp_ids{}, identity[] (name, colors, rarity, mana_value, image urls)}` + `features.f32` raw blob (or the precomputed `card_table.f32 [N,256]` tied to `model_id`). Add a Python exporter beside `build_set_assets.py`. Avoids parsing NPY UTF-32 strings in TS.

### 3.3 Startup (once per set)

1. Refuse if `meta.manifest_hash != assets.manifest_hash`.
2. Upcast features to f32; if width > `feat_dim` truncate columns to `feat_dim` (391-d model on 775-d table drops trailing text dims; anything else is a different manifest).
3. Run `card_encoder` once → `table [N,256]`.
4. `grpToRow`: for each name row, for each alias grpId, first row wins.
5. `setScalars = [N/400, ppp==13, ppp==14, ppp==15]` (N = number of names/rows: MSH 334/400 = 0.835).

### 3.4 Per-pick scoring (`score_pack(pack, pool, pack_number?, pick_number?)`, draftfm.py L157-208)

- **Pool**: rows of known pool grpIds (unknown silently dropped); if none → `pool_emb = pool_null_input[1,1,256]`, `pool_counts=[[0]]`, `pool_mask=[[false]]`. Else `np.unique` (sorted asc) rows, counts capped at 8, mask all false. Aliases of one name collapse into one slot.
- **Pack**: `known = sorted(unique known rows)`; K = count of distinct known rows (not len(pack)); if none → all ev None. `pack_emb = table[known]`, `pack_mask` all false.
- **Position** (0-INDEXED 17Lands: pack ∈ {0,1,2}, pick ∈ [0,ppp−1]): if EITHER arg is null BOTH are derived from `len(pool)` (`pack = pool//ppp`, `pick = pool%ppp`; unknown pool grpIds still count). `position = [pack==0, pack==1, pack==2, pick/ppp, max(ppp-1-pick,0)/ppp, poolSize/45, min(poolSize/(3*ppp),1)]` with `poolSize = pack*ppp+pick`.
- **Feed** the 10 tensors; `logits[0]` map back per input grpId via row (aliases share a logit); unknown → null.
- **rank_scores** (`base.py` L35-56): softmax over known evs (keyed by grpId, so duplicates share prob), stable sort by `(ev is None, -ev)`, unknown last, 1-based rank.
